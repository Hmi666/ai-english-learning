## 2. 导入范围

上游仓库包含多个端和多个技术栈版本，本项目只导入其中两个工程：

| 上游目录 | 导入到本仓库 | 说明 |
|---|---|---|
| `smart-admin-api-java17-springboot3` | [`backend/`](../backend) | Java 17 + Spring Boot 3 后端 |
| `smart-admin-web-typescript` | [`frontend/`](../frontend) | Vue 3 + TypeScript 前端 |
| `smart-admin-api-java8-springboot2` | 未导入 | Java 8 版本，与技术基线不符 |
| `smart-admin-web-javascript` | 未导入 | JavaScript 版本，技术基线要求 TypeScript |
| `smart-app` | 未导入 | 移动端，一期范围为 Web |
| `数据库SQL脚本/mysql/smart_admin_v3.sql` | [`database/migrations/V3.31.0__smart_admin_baseline.sql`](../database/migrations/V3.31.0__smart_admin_baseline.sql) | 脚手架全量建库脚本 |
| `数据库SQL脚本/mysql/sql-update-log/*.sql` | [`database/migrations/updates/`](../database/migrations/updates) | 历史增量脚本，仅作参考，基线脚本已包含其最终结构 |

未导入的目录不进入本仓库，避免引入与技术基线无关的代码和裁剪成本。

## 5. 一期未启用的脚手架能力

`技术架构.md` 第 1.2 节已确认一期只保留登录、角色权限、用户管理、操作日志和代码生成辅助能力。以下上游模块代码仍然存在于仓库中，但一期不作为业务功能启用，也不会作为验收项：

- 工作流、低代码、报表和大屏相关模块；
- 短信、邮件、多数据库适配和复杂加密传输；
- 与学习业务无关的后台示例模块（商品、分类等）。

上游自带的示例业务模块只能作为基础设施参考，不得直接当作本项目的学习内容、学习任务、测验和学习记录模型使用。
